## 1. 设计概念

### 1.1 一句话

> 一方深色砚台，散落着被时间打磨过的数字石片；玩家将它们叠起，直至一枚鎏金的「一〇二四」在山巅亮起。

### 1.2 视觉关键词

`宣纸` · `松烟墨` · `朱砂印` · `鎏金` · `楷体` · `石片` · `等高线` · `克制` · `手作`

### 1.3 叙事框架

游戏被包装成一本「数字山房」的纸上游戏册：

- 标题「叠山」既是玩法，也是隐喻；
- 一〇二四是目标，也是一枚印章；
- 山径是可量化的进度；
- 画面不强调科技感，而强调书卷、手作与安静的专注；
- 界面英文仅作为版式装饰，不作为主要信息语言。

### 1.4 设计原则

1. **纸与墨的对比**：背景是温暖的纸，棋盘是深沉的墨；视觉重心自然落在游戏区域。
2. **一个红色就够**：朱砂作为唯一的强强调色，用于印章、关键操作、峰值和焦点。
3. **让材质说话**：方块要像可以触摸的纸片/石片，通过高光、内描边、底部阴影和细微角标制造厚度，而非依赖图片纹理。
4. **层层递进**：方块随数值从石色、苔绿、松绿、朱砂，最终到鎏金，形成可读的“登峰”色彩叙事。
5. **安静但有回应**：动效短、轻、克制；只有在合并、得分、无效移动、登峰时给予反馈。
6. **文字有语气**：文案不使用互联网营销腔，采用克制、诗性、准确的中文。

## 2. 颜色系统

### 2.1 核心色板

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#ECE3D0` | 页面主背景、纸张 |
| `--paper-high` | `#F5EDDB` | 高光纸色、弹窗底色、深色底上的文字 |
| `--paper-deep` | `#DCCDB2` | 纸张暗部、细节 |
| `--ink` | `#20251F` | 主文字、主按钮、深层墨色 |
| `--ink-soft` | `#565A4F` | 次要文字、说明 |
| `--ink-faint` | `#6C6859` | 辅助信息、英文注记 |
| `--cinnabar` | `#A53C28` | 朱砂印、强调、目标、焦点 |
| `--cinnabar-deep` | `#7C2A1C` | 朱砂阴影、深色强调 |
| `--gold` | `#C8A159` | 登峰、鎏金、装饰边 |
| `--line` | `rgba(32, 37, 31, 0.17)` | 分隔线、细边界 |
| `--line-strong` | `rgba(32, 37, 31, 0.32)` | 较强边界 |

### 2.2 棋盘与格子

| 元素 | 色值 / 方式 |
| --- | --- |
| 棋盘底 | 深墨绿径向渐变：`#232C22 → #151B16 → #0D120E` |
| 棋盘格 | 纸张色 5.2% 透明叠加，内阴影加强凹陷感 |
| 棋盘边框 | 深绿黑金属渐变，外加金色内描边 |
| 格子角线 | 纸张色或金色，约 3–5% 不透明度 |

### 2.3 方块色阶

从低值到高值，颜色完成从“石”到“苔 / 松”再到“朱砂 / 金”的上升叙事。

| 数值 | 背景渐变（近似） | 文字色 | 说明 |
| --- | --- | --- | --- |
| `1` | `#D5C9B2 → #E7DECA` | `#585C50` | 灰石纸片 |
| `2` | `#E7DCC6 → #F2E9D7` | `#2B2F27` | 米纸白 |
| `4` | `#D8C29B → #E7D5B2` | `#2B2C22` | 砂色 |
| `8` | `#B89B63 → #CFB682` | `#2E2A1E` | 暖赭 |
| `16` | `#84966F → #9EAA89` | `#23281F` | 淡苔绿 |
| `32` | `#61795A → #7B8F6D` | `#F3EBD8` | 松苔 |
| `64` | `#3C5540 → #536C56` | `#F5EDD9` | 深松 |
| `128` | `#99432A → #B3593A` | `#FBF0DC` | 初朱砂 |
| `256` | `#87321F → #A8442C` | `#FBF0DC` | 正朱砂 |
| `512` | `#5D2018 → #7F3023` | `#F6E8CE` | 暗绛 |
| `1024` | 鎏金渐变 + 左上高光 | `#2B2111` | 目标、金属箔 |
| `> 1024` | `#0D120E → #20281F` | `#C8A159` | 越峰，深墨底金字 |

方块材质由以下视觉层构成：

1. 渐变底；
2. 顶部 1px 高光；
3. 底部 2px 暗边；
4. 投影（给棋盘方向）；
5. 内缩 4px 的极低对比细框；
6. 高值方块额外发光或流光。

### 2.4 色彩使用规则

- 朱砂只用于：目标印、印章、主按钮焦点、峰值和重要强调。
- 金色只用于：1024 方块、棋盘五金细节、关键焦点（深色按钮）。
- 不使用大面积高饱和红、紫或蓝。
- 不依靠颜色作为唯一信息源：数值同时通过数字、字号和层级表达。
- 装饰性金色和内边框保持低透明度，避免抢走方块数字的注意力。

## 3. 字体与排版

### 3.1 字体系

| 用途 | 字体栈 | 说明 |
| --- | --- | --- |
| 中文展示（标题、引语） | `STKaiti → KaiTi → Kaiti SC → Noto Serif SC → serif` | 楷体笔意，形成手写书卷感 |
| 中文正文 / UI | `STSong → Songti SC → Noto Serif SC → SimSun → serif` | 宋体阅读感 |
| 数字 / 英文 / 元数据 | `Cormorant Garamond → Bodoni MT → Didot → Georgia → Times New Roman → serif` | 高对比衬线，构成页面的“秩序感” |
| 系统备用 | 操作系统衬线字体 | 中文缺少指定字体时自然回退 |

**Cormorant Garamond** 以内嵌可变字体形式提供（字重 300–700，包含常规与斜体 Latin 子集），确保数字、英文小标和元信息保持统一风格，不依赖网络。

### 3.2 排版比例

| 层级 | 字号 | 字体 | 特征 |
| --- | --- | --- | --- |
| 页面主标题 | `clamp(82px, 10.4vw, 148px)` | 楷体 | 行高 0.76，极紧，字形成为图形 |
| 短屏主标题 | `clamp(78px, 8vw, 104px)` | 楷体 | 保留气质但压缩高度 |
| 引言主句 | `clamp(25px, 2.55vw, 34px)` | 楷体 | 朱砂强调关键词 |
| 得分数字 | `clamp(46px, 4.35vw, 64px)` | Cormorant | 600 字重，紧凑行高 |
| 最佳成绩数字 | `clamp(38px, 3.55vw, 52px)` | Cormorant | 次要层级，墨灰 |
| 弹窗标题 | `clamp(30px, 4.3vw, 38px)` | 楷体 | 舒展、留白 |
| 正文 / 说明 | 12–13px | 宋体 | 行高 1.8–2.05，宽阔 |
| 小标签 | 9–12px | 宋体 / Cormorant | 字距 0.1–0.2em |
| 数字方块 | `cell × 0.45` 起，按位数缩小 | Cormorant | 行高 0.84，数字紧凑 |
| 页脚 | 9px | 宋体 | 宽字距，像书籍版权页 |

### 3.3 字距与排版细节

- 英文小标签使用大写 + 宽字距（0.12–0.5em）。
- 中文标签字距较小（0.08–0.16em），以保持阅读流畅。
- 大标题字距可轻微收紧（`-0.045em`），字形更紧凑。
- 所有数字使用 `lining-nums` 与 `tabular-nums`，避免跳动。
- 中文与英文/数字混排时不额外插入空格；视觉呼吸由字号、字距和细线建立。

### 3.4 字号与方块位数

| 位数 | 字号比例 |
| --- | --- |
| 1–2 位 | 约 0.42–0.45 × 格宽 |
| 3 位 | 约 0.345 × 格宽 |
| 4 位 | 约 0.285 × 格宽 |
| 5 位 | 约 0.235 × 格宽 |
| 6 位及以上 | 约 0.2 × 格宽 |

这样 `1024`、`2048`、`16384` 等值在边缘仍留出安全边距。

## 4. 布局与空间

### 4.1 页面网格

- 页面最大宽度：`1240px`。
- 水平内边距：`clamp(18px, 4.2vw, 56px)`。
- 桌面端主体两栏：
  - 左：信息栏，最大 `322px`；
  - 右：棋盘区，最大 `608px`；
  - 中间为大尺度留白，制造页面呼吸和不对称的编辑感。

### 4.2 刊头

- 刊头采用两栏：左侧标题区块，右侧引言区块。
- 标题区块包含栏目标记、巨大「叠山」与竖排朱砂印。
- 引言区块左侧以一条极细分隔线与标题区分，并在底部有一条带朱砂短线的水平边界。
- 桌面短屏模式压缩刊头比例，以优先保留完整棋盘。

### 4.3 间距系统

项目没有建立一组命名 spacing tokens，而是通过 `clamp()` 和局部设计值共同形成节奏：

| 场景 | 典型范围 |
| --- | --- |
| 页面顶部留白 | 20–50px |
| 刊头底部间距 | 17–34px |
| 主体上下间距 | 18–44px |
| 信息块之间 | 20–34px |
| 棋盘框内边距 | 9–14px |
| 网格间隙 | 8–12px（移动端 7px） |
| 卡片内边距 | 26–50px |
| 主要圆角 | 0–3px（整体保持硬朗纸面感） |

### 4.4 棋盘空间

- 棋盘外壳包含明显的内边框和四角铜色角花，像木框或石框。
- 棋盘内部是深色网格，与纸面形成强烈对比。
- 方块与网格之间保持 8–12px 间隙，保证滑动时视觉分离。
- 棋盘在对局中必须始终为正方形，不因视口高度裁切。

### 4.5 响应式布局

| 视口 | 布局 |
| --- | --- |
| `> 1100px` | 完整双栏、大字号刊头 |
| `961–1100px` | 双栏压缩，尺寸缩小 |
| `≤ 960px` | 刊头堆叠，信息分两栏，棋盘居中 |
| `≤ 700px` | 信息单栏，棋盘近全宽，移动端提示替代键盘提示 |
| `≤ 430px` | 更紧凑的标题、隐藏引言正文和英文辅助标签 |
| 桌面短屏（宽度 ≥ 961px、高度 ≤ 960px） | 缩小刊头，按视口高度计算棋盘上限 |

## 5. 组件规范

### 5.1 标题与朱砂竖印

- 标题「叠山」用楷体、极大字号、紧行高；第二个字略微下沉，增加手工排字感。
- 主标题旁有朱砂竖印，宽约 25–31px，四字「一〇二四」从上到下排列。
- 印章使用内描边、轻微旋转和投影，模拟真实印泥。
- 短屏时印章整体缩小，避免撑高标题区。

### 5.2 得分账簿

- 类似刊物中的数字账页，上方为细墨线，内部两列由一条竖线分隔。
- 标签和英文注记位于上方，数字紧随其下。
- 当前得分为主数字（深墨），最佳成绩为次数字（墨灰、字号略小）。
- 得分增加时数字轻微上跳，增幅以小号朱砂字向上飘出并淡出。

### 5.3 尺寸选择

- 以两枚并列的“账簿页签”呈现，不使用常见的胶囊形分段控件。
- 选中项为深墨底、米白字，并在底部出现一条细金线；未选中项保持透明纸面。
- 四格与五格的英文/数字缩小，作为次要信息。
- 小屏仅保留中文主标签，避免拥挤。

### 5.4 新局按钮

- 由朱砂方形印章「新」与文字「另起一局」组合。
- 边框极细，纸面透明；悬停时才增加背景和轻微边框强调。
- 印章悬停时旋转约 4°，模拟盖印前的轻微移动。
- 小屏缩减为印章 + 短文案，仍需保持最小点击高度约 48px。

### 5.5 棋盘框

- 深色木框/砚台质感，使用对角渐变和内外高光。
- 内侧有 1px 的鎏金低透明描线；四角有铜色 L 形角花。
- 棋盘本身的方形与阴影构成页面视觉重心。
- 不允许圆角过大；整体圆角 2px 左右，保持器物硬朗感。

### 5.6 数字方块

- 方块以纸质/石片为视觉隐喻，不使用扁平色块。
- 表面有斜向高光与底部暗边，形成“可以拿起”的厚度。
- 数字本身是唯一内容；不做额外图标或进度装饰。
- 所有数值使用衬线数字，字重 600；`1024` 使用 700 和金色材质。
- 合并时放大回弹，新方块出现时从较小尺寸淡入。
- 方块进入棋盘与合并的动画都使用柔和的 `cubic-bezier`。

### 5.7 山径

- 位于棋盘下方，是一条极细的水平径线。
- 10 个里程碑点对应 `2, 4, 8, …, 1024`。
- 已达成的点变为墨色，当前峰高为朱砂色并稍大。
- 终点使用稍大的金色圆点，登峰后文案切换为「登峰 · 1024」。
- 装饰性强，但同时也是最高方块的进度指示。

### 5.8 弹窗

- 全屏遮罩，深墨半透明并带毛玻璃模糊。
- 卡片为奶白纸面，四周有细内框。
- 顶部有一枚超出卡片边缘的朱砂方印，像盖在纸上的章。
- 标题用楷体，说明用宋体，成绩数字用 Cormorant。
- 主按钮为深墨底，次按钮为透明描边；在失败弹窗中主次关系会根据唯一可行动作调整。
- 入场动效：遮罩淡入、卡片上浮、印章旋转落下。

### 5.9 页脚

- 细横线 + 小号宋体 + 宽字距。
- 像书籍的版权页，不承载功能。
- 包含游戏名和一句视觉口号。

## 6. 动效规范

### 6.1 动效目标

- 用物理性的变化表达游戏状态：移动、合并、出现、受限。
- 不添加装饰性的持续漂浮、闪烁或背景动画。
- 1024 的流光可以持续，但速度极慢且低对比，不干扰阅读。

### 6.2 时间与缓动

| 动效 | 时长 | 缓动 |
| --- | ---: | --- |
| 方块滑动 | 150ms | `cubic-bezier(0.22, 0.7, 0.2, 1)` |
| 方块合并 | 300ms | `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| 新方块出现 | 250ms | `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| 分数跳动 | 360ms | 自定义 |
| `+N` 增量 | 900ms | `cubic-bezier(0.2, 0.7, 0.2, 1)` |
| 无效回弹 | 300ms | `ease` |
| 载入上浮 | 850–950ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 弹窗卡片 | 550ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 印章落下 | 600ms | `cubic-bezier(0.2, 0.8, 0.2, 1)` |

### 6.3 减少动态效果

- 在系统开启“减少动态效果”时，所有动画缩短至近乎即时。
- JS 逻辑等待时间同步降低，避免“看不到动画但输入仍被锁定”的不一致。
- 游戏结果、得分和状态更新仍会立即反映。

## 7. 背景与材质

页面背景由四层构成：

1. **纸色渐变**：暖米色基底，左上略亮、右下略带朱砂暖意。
2. **等高线**：重复径向渐变模拟地形图，透明度极低，遮蔽边缘。
3. **日晕与远山**：左上角模糊的朱砂光环、右下角巨大的淡墨「山」字，增加叙事空间。
4. **颗粒**：内联 SVG 噪声滤镜生成纸张颗粒，叠加在页面上，透明度约 16%，混合模式为 multiply。

这些装饰均不承载信息，不响应鼠标，不影响性能和可读性。

## 8. 文案与语气

### 8.1 语气原则

- 短句、克制、略带古意。
- 避免叹号、网络热词、过度口语。
- 中文主标题不超过四个字。
- 英文仅作为小型版式元素，不大写成长句。
- 操作提示保持准确清晰，不因诗意而含糊。

### 8.2 命名

| 概念 | 常用文案 | 不使用 |
| --- | --- | --- |
| 分数 | 得数、此格最佳 | 分数爆表、最高分记录 |
| 新局 | 另起一局 | 重新开始游戏 |
| 胜利 | 山成、已见千峰 | 你赢了！ |
| 失败 | 山止、无处可叠 | 游戏结束 |
| 目标 | 合至一〇二四 / 1024 | 达到 1024 分 |

## 9. 可访问性与视觉

- 焦点样式清晰：纸面按钮使用朱砂或墨色 outline，深色按钮使用金色 hairline。
- 大数字方块本身就是最大的信息；低值方块使用深墨字，高值深色方块使用米白字，保证基本可读。
- 不仅依赖颜色：当前尺寸有 `aria-pressed`，峰值/目标有文字，胜负弹窗有大标题和描述。
- 动效可关闭；色彩对比不做唯一区分。
- 文本行高宽松，字号在小屏上不缩小到不可读。
- 控件点击区域尽量保持 40px 以上。

> 本设计已考虑可访问性基础，但未进行正式 WCAG 认证。

## 11. 扩展设计建议

### 可继续探索的方向

- **月夜主题**：墨蓝纸面、冷银方块、白色印泥；
- **青瓷主题**：灰青底、粉青与釉里红方块；
- **朱砂主题**：更浓的红色纸面，金色仅用于终点；
- **无障碍高对比变体**：提高低值方块与文字的对比，减少纸张纹理；
- **动态纸纹**：非常缓慢的纸面纹理漂移（需尊重减少动效偏好）。

### 不建议的方向

- 大面积渐变紫、霓虹、玻璃拟态；
- 过圆角、过大阴影的“应用卡片”风格；
- 将印章、书法变成无意义的贴图堆叠；
- 使用太多红金同时争夺注意力；
- 用颜色区分唯一的游戏状态；
- 移除系统级键盘焦点提示。
